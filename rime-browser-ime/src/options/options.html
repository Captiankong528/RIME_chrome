    使用说明

    一、打开与关闭

    • 按 Ctrl+Shift+Space 直接开关；或者点工具栏上的扩展图标， 在弹出的小面板里点「开启 / 停用输入法」。
    • 图标上的徽标显示 中 表示已开启，EN 表示已关闭。
    • 小面板里还能直接换输入法和简繁；候选数、自检、说明在这个设置页里 （面板底部有入口）。
    • 开关是全局的：打开后所有标签页都能打中文。快捷键没反应就去 chrome://extensions/shortcuts 自己设一个。

    二、在网页上打字

    • 开关打开后，在任意网页的输入框、多行文本框或富文本编辑区里直接敲编码。
    • 候选窗会跟着光标出现；组字过程中网页上不会出现英文字母，只有候选窗里有编码。
    • 支持 Shadow DOM 里的输入框（YouTube、Reddit 这类站点）。

    三、按键

    空格 / 1–9选取对应候选并上屏（空格取第一个）
    Enter把当前编码原样上屏（打英文、符号用）
    Esc取消本次组字，什么都不上屏
    Backspace删掉一个编码字符
    - / =候选上一页 / 下一页
    PageUp / PageDown同上
    ↑↓←→移动高亮的候选（是否生效取决于方案）
    F4组字中循环切换输入法
    Ctrl+Shift+4切换简体 / 繁体（朙月拼音、双拼、地球拼音等带此开关的方案）
    Shift+字母直接上屏该大写字母
    Ctrl/Alt/Cmd+其他键不拦截，交给网页，不影响网站快捷键
    没在组字的时候，本扩展只接管「可打印字符」、F4 和 Ctrl+Shift+4。 Backspace、方向键这类功能键一律放给网页，所以不会影响正常的编辑操作。

    四、切换输入法

    • 在上面的「当前输入法」下拉框里选，或者组字过程中按 F4。
    • 也可以点工具栏图标：弹出的小面板里有输入法和简繁两个下拉框， 选完立刻生效，选择会记住。
    • 也可以在网页右下角的状态栏上点：点输入法名字展开方案列表（按 音码 / 双拼 / 注音 / 形码 分组），点一下就切过去；简繁那组点「跟随 / 简 / 繁」 （注音是「跟随 / 简 / 臺 / 繁」）立刻换字形，选择会记住；点最右边的 ⌄ 把状态栏收成一颗小胶囊，再点一下展开。
    • 第一次切到某个输入法需要把它的词典装进引擎（几 MB），会有几秒的 「正在装载…」，之后切换就是瞬间的。
    • 选择会记住，浏览器重启后仍然生效。
    • 简繁默认跟随浏览器语言：界面语言是 zh-TW / zh-HK / zh-MO / zh-Hant-* 时默认出繁体，其余（含 zh-CN、 en-US）默认出简体。在状态栏或工具栏面板上手动选过之后就不再跟随语言， 改用你选的那个；想回到跟随语言就点状态栏上的「跟随」（面板里是「跟随浏览器语言」）。打字过程中也可以按 Ctrl+Shift+4 临时切到另一边（不改变上面这个选择）。

    五、数据与隐私

    • 引擎（librime 的 WebAssembly 产物）和所有输入方案都打包在扩展里， 不联网、不发任何请求、不上传输入内容。
    • 你选过的词、词频统计保存在浏览器的 IndexedDB 里，只在本机。
    • 想清空就点下面的「清空用户词频」。

    六、已知限制

    • 不接管密码框和 type=number 的输入框。
    • 页面自带的输入法（比如系统中文输入法）优先：检测到正在组字时会让行。
    • chrome:// 等浏览器受保护页面无法注入，用不了。
    • iframe 里的候选窗会被 iframe 的边界裁剪，跨域 iframe 尤其明显。
    • 状态栏固定在右下角，暂时不能拖动或改位置；它只在顶层页面显示 （iframe 里不重复显示——同一套引擎，一个页面一条就够了）。

    七、出问题了怎么办

    1. 先点上面的 运行自检：它会逐层跑 background 路由 → offscreen/引擎 → 方案装载 → 打字上屏， 哪一层断了直接显示原因。
    2. 后台日志：chrome://extensions → 本扩展 → 点 Service Worker 链接。
    3. 页面日志：网页里按 F12，过滤 [rime] 或 [librime]。
    4. 改完源码后需要回 chrome://extensions 点一次「重新加载」。
